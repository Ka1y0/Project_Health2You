# Health2You

`Project_Health2You` is the public engineering home for Health2You. It is intended to collect material that has been deliberately approved for public release, including technical design notes, selected algorithm work, adaptive UI and layout studies, health-chart design, Apple-platform UI research, and legal or support resources.

## Current status

This repository is being formed gradually. Its initial public content is the Health2You Legal & Support site migrated from the retired legacy Legal repository; no Health2You algorithm implementation or production application source is included in this initial release.

This repository is **not** a publication of the complete Health2You production app. The presence of design notes or selected implementation work here should not be interpreted as making unreleased application source public.

## Repository layout

- `Legal/` — publication notes and navigation for public legal and support resources.
- `docs/` — the static GitHub Pages publication directory.
- `Algorithms/` — reserved for selected algorithm material explicitly approved for public release.
- `UI/` — reserved for public UI adaptation, layout, chart, and visual implementation material.
- `Engineering/` — reserved for other approved public technical documentation.

Empty or introductory sections describe intended organization only; they do not claim that unreleased work is already available.
